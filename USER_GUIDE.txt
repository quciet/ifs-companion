IFsCompanion 0.1.0

Run IFsCompanion-Setup-0.1.0-win-x64.exe, then open IFsCompanion from the
Start menu or desktop shortcut. The interface opens directly in its own window.
Close that window to quit. There is no separate browser or companion launcher.

1. Open Settings and browse to your IFs installation folder (containing DATA and RUNFILES).
2. Open Tools > Model Vetting. Choose the baseline and comparison runs.
3. Load shared variables, select outputs, and compare.
4. Click a result or audit row to inspect trajectories. Save CSVs or SVG charts.

Python, NumPy, and .NET are bundled. Setup automatically installs Microsoft
WebView2 if missing; that step requires an internet connection. Subsequent
comparison work runs locally. IFs and model files are not included.

Settings, results, tools, logs, browser data, and temporary files default to the
"data" folder beside IFsCompanion.exe. Choose another empty folder in Settings >
Storage, then close and reopen Companion. Saved files are copied and verified;
after switching locations, the originals are removed automatically. The transfer
temporarily needs space for both copies, but keeps no permanent backup. If old
files cannot be removed, Settings reports this and cleanup retries at next launch.
Changed or unexpected files in the old folder are preserved.
Browser caches and temporary files are rebuilt. Explicitly chosen output/export
locations remain unchanged. Earlier LocalAppData data is imported on first launch.
Updates and uninstall preserve saved data and the adjacent storage.json setting.
The app folder must be writable. IFS_VETTING_DATA_DIR overrides the saved choice.
Closing while a tool is doing work asks whether to interrupt it.

For portable use, extract the complete ZIP and open IFsCompanion.exe.
Keep all extracted files and the engine folder together. WebView2 must already
be installed; use the installer if it is missing.

Requires Windows 10 version 1809 or later, or Windows 11, x64.
Model comparison is included. Autotune is available as an optional tool.
Code Interpreter is available as a separate tool package for Companion 0.1.2 or later.
1. Open Settings > Manage tools > Add from file and select the Code Interpreter .ifstool.
2. In Settings > AI connection, enter your Chat Completions-compatible API base URL,
   model identifier, and API key. Keys are encrypted for your Windows account.
3. Open Code Interpreter from Tools. Choose bundled source or local source folders,
   then select Prepare index. Your IFs installation does not need to include code.
4. Ask a question to use your configured AI provider, or Search code to work offline.
   Asking sends the question and selected source excerpts to the configured provider.
5. Click an answer citation to read its code excerpt. Answers retain source revisions
   or file fingerprints; they do not prove compatibility with your installed IFs.
Back and Stop preserve selections and saved answers. Updates and uninstall preserve
this tool's data. Rebuild the index after changing source files or updating the bundle.
The main Companion chat remains guided. Scenario Builder is optional: install its .ifstool package through Manage tools, then open Tools > Scenario Builder. It uses the shared AI connection to create or modify scenarios. Attach an optional UTF-8 .sce file, review the draft and annual values, then save a new file. Saved files are in the per-tool data folder under scenarios. See README.md for details.
The app provides numerical evidence; reviewers decide whether changes are expected.

INSTALLING OPTIONAL TOOLS

1. Save the .ifstool package shared by your team to your computer.
2. In Companion, open Settings > Manage tools > Add from file.
3. Choose the package and confirm that you trust its source.
4. Wait for the ready message. Large packages can take a few minutes.
5. Open the tool from Tools. It appears inside Companion's right panel.

Autotune includes its own Python and Electron runtime. You do not need to
install development software. The shared IFs folder is prefilled when the tool
starts; use the tool's validation step before running experiments.

To manage installed tools, open their (...) menu. Official tools offer Update,
Update from file, and Uninstall. Other tools offer Update from file and Uninstall.
Stop active work first; idle tools close automatically. Uninstall removes the
sidebar entry and preserves settings and saved work. Removing the included
comparison tool disables it until reinstalled; bundled program files remain.

For available official tools, use the + menu to Install online or Install from
file. The catalog refreshes when this screen opens. Update is enabled only for
a newer compatible official release. Online installation needs internet access,
but no GitHub account. Add from file also works offline.

File installs can use a beta or older version after confirmation. Older versions
may not support data saved by newer versions. Only use trusted packages.

Tool rows show download and approximate installed size. Choose Release details
from a tool menu for its version, date, requirements, and release notes.
Installed and newer official releases are shown separately. Saved work and
generated indexes are not included in the sizes.
