Release notes
Downloads are verified against the release SHA256 checksums. Installed copies can launch the verified installer; portable copies must be closed before replacing program files. Keep the data folder and storage.json. Optional tools update separately in Manage tools.
Storage
Store Companion settings, saved work, tools, caches, and temporary files together.
Close and reopen Companion to apply a change. Saved data is copied and verified, then the original is removed automatically. The transfer temporarily needs space for both copies. Browser cache and temporary files are rebuilt. Files exported elsewhere stay where you saved them.
IFs installation
Changing the installation affects new comparisons. Existing jobs and reports retain their original inputs.
Tool management
Add or update tools using a package shared by your team.
AI connections
Save named connections and choose which one your AI tools use.
Validate connection fills the model dropdown without using model tokens. Manual entry is always available. Testing does not save changes.
